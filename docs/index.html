ce-net / Live systems / References

Anything to anything.

One kind of name reaches a file on a laptop, a blob, a repo file at a commit, a node, a person, an agent key, a cell op, a capability and an enterprise system wrapped as a cell. A name says where the thing lives now, follows it when it moves, and with a pin refuses any bytes that changed. Every step below is a signed call between two devices, replayed from the recorded run.

      What links to the record

      The grant

      Written in CAL, compiled and signed with ce-net-proto. The compiled link keeps only pinned values: the report file is its content hash, so the executor hashes the bytes it fetched before it acts.
      


      Check it yourself
      

      

      git clone https://github.com/ce-net/live-refs && cd live-refs && cargo run -- sim starts four device processes on your machine, runs the eight steps and writes proof/run.jsonl. cargo run -- verify proof checks every step's signature, the hash chain between steps, and that each answer is signed by the device that gave it. No network, keys or accounts are needed.
      

      The ids are byte-identical to the reference implementation (). The sim run and the ops-1 run shown here are in this repo.
